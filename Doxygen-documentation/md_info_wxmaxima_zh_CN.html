wxMaxima 用户手册

WxMaxima 是计算机代数系统（CAS） Maxima 的图形用户界面（GUI）。借助 WxMaxima 可以使用 Maxima 的全部功能。此外，它还为最常用的功能提供了方便的向导。本手册介绍了一些使 wxMaxima 成为 Maxima 最受欢迎的图形界面之一的功能。

wxMaxima 简介

<em>Maxima</em> 与 wxMaxima

在开源领域，大型系统通常会被拆分为若干较小的项目，以便小型开发团队更容易管理。例如，一个光盘刻录程序会由一个真正负责刻录光盘的命令行工具和一个图形用户界面组成，后者让用户无需了解所有命令行开关、甚至完全不用命令行就能使用它。这种方式的一个优点是，投入到命令行程序中的开发工作可以被许多程序共享：同一个命令行刻录程序既可以用作文件管理器的“发送到光盘”插件，也可以用作音乐播放器的“刻录到光盘”功能，还可以用作 DVD 备份工具的刻录组件。另一个优点是，把一个大任务拆分为较小的部分，使开发者能够为同一个程序提供多种用户界面。

一个像 Maxima 这样的计算机代数系统（CAS，computer algebra system）也适合前述框架。Maxima 可以用作任意精度计算器程序的底层软件，也可以在更大计算系统中作为公式转换程序来帮助计算（例如 Sage）。Maxima 也可以直接作为独立的计算系统使用，它可以通过命令行来访问。然而，在通常情况下，像 wxMaxima 这样的用户界面是使用 Maxima 的一种更有效的方法，特别是对于新手而言更是如此。

<em>Maxima</em>

Maxima 是一个功能齐全的计算机代数系统（CAS）。CAS 是一个程序，它可以通过对公式变形并找到问题的解来求解数学问题，而不是仅仅输出结果的数值。换言之，Maxima 可以作为一个计算器，给出变量的数值表示，也可以提供解析解。此外，它还提供了一系列数值分析方法，用于求解没有解析解的方程或方程组。

Maxima 的详尽文档可以 在互联网上获取。其中一部分文档也可以通过 wxMaxima 的帮助菜单访问。按下帮助键（在大多数系统上是 F1 键）时， wxMaxima 的上下文相关帮助会自动跳转到 Maxima 手册中介绍光标所在命令的页面。

WxMaxima

WxMaxima 是一个图形用户界面，提供了 Maxima 的全部功能和灵活性。WxMaxima 为用户提供图形化的显示以及许多让 Maxima 更易于使用的功能。例如，只需单击鼠标右键， wxMaxima 就能把任意单元格的内容（如有需要，也可以是公式的任意部分）导出为文本、LaTeX 或 MathML。甚至可以把整个工作簿导出为 HTML 文件或 LaTeX 文件。 wxMaxima 的文档（包括演示其用法各个方面的工作簿）可以在 wxMaxima 的 帮助网站 上在线获取，也可以通过帮助菜单访问。

在 wxMaxima 中输入的计算式是由 Maxima 命令行工具在后台执行的。

工作簿基础

wxMaxima 的大部分功能一看就懂，但有些细节需要注意。 这个网站 提供了许多介绍 wxMaxima 各方面功能的工作簿。学习其中的一些（尤其是“10 分钟 _(wx)Maxima_ 教程”）有助于熟悉 Maxima 的内容以及如何使用 wxMaxima 与 Maxima 交互。本手册着重介绍 wxMaxima 中那些不太直观、在线资料中也可能未涉及的方面。

工作簿的工作方式

wxMaxima 为数不多的非标准之处之一，是它把交给 Maxima 的数据组织成单元格，只有在用户要求时才对其求值（也就是发送给 Maxima_）。对单元格求值时，该单元格中的所有命令（且仅限该单元格）会作为一批被求值。（这种说法并不完全准确：可以选中若干相邻的单元格一起求值，也可以让 _Maxima 一次性对工作簿中的所有单元格求值。） WxMaxima 提交命令执行的方式初看可能有些陌生。但它大大简化了大型文档的处理（用户并不希望每次修改都自动触发整个文档的重新求值）。此外，这种方式也非常便于调试。

单元格

工作簿由单元格组成。WxMaxima 支持以下几种单元格类型：

  • 数学单元格，包含一行或多行 Maxima 输入。
  • Maxima 的输出或它提出的问题。
  • 图像单元格。
  • 文本单元格，例如可用于编写说明文档。
  • 标题、节或小节。最多可以有 6 级不同的标题。
  • 分页符。

当输入文本时，wxMaxima 的默认行为是自动创建一个数学单元格。可以使用“单元格”菜单、菜单中显示的热键或工具栏中的下拉列表创建其他类型的单元格。一旦创建了非数学单元格，输入到文档的任何内容都将被解释为文本。

水平光标与垂直光标

如果用户试图选中一个完整的句子，文字处理软件会尝试把选区自动扩展到以单词边界开始和结束。同样，如果选中了不止一个单元格， wxMaxima 会把选区扩展到完整的单元格。

不同寻常的是， wxMaxima 通过定义两种光标来提供拖放的灵活性。 WxMaxima 会在需要时自动在两者之间切换：

  • 如果光标在两个单元格之间移动或单击，则会使用水平光标；
  • 在单元格内部工作的垂直光标。用鼠标指针或方向键把光标移入单元格时，会启用这种光标，它的工作方式与文本编辑器中的光标非常相似。

启动 wxMaxima 时，只会看到闪烁的水平光标。开始输入后，会自动创建一个数学单元格，光标也会变成普通的垂直光标（作为提示符会显示一个向右的箭头；数学单元格求值（CTRL+ENTER）后，会显示标签，例如 (i1)、 (o1)）。

开始创建工作簿时，您也许想先创建另一种类型的单元格（使用“单元格”菜单），例如标题单元格或文本单元格，用来说明接下来要做什么。

在不同单元格之间移动时，也会看到（闪烁的）水平光标，可以在该位置向工作簿插入单元格（直接开始输入公式即可插入数学单元格，或者通过菜单插入其他类型的单元格）。

将单元格发送给 Maxima

按下 CTRL+ENTER、 SHIFT+ENTER 或小键盘上的 ENTER 键，即可执行代码单元格中的命令。 wxMaxima 默认在按下 CTRL+ENTER 或 SHIFT+ENTER 时发送命令，但也可以把 wxMaxima 配置为按下 ENTER 即执行命令。

命令自动补全

WxMaxima 具有自动补全功能，可通过菜单（单元格/自动补全）或按组合键 CTRL+SPACE 触发。自动补全会考虑上下文。例如，在 ezUnits 的单位说明中触发时，它会列出适用的单位。

除了补全文件名、单位名或当前的命令名、变量名之外，自动补全还能为大多数命令显示一个模板，指明该命令所需参数的类型（和含义）。要使用此功能，请按 SHIFT+CTRL+SPACE 或选择相应的菜单项（单元格/显示模板）。

希腊字母

计算机一般以 8 位值（8-bit）存储字符，所以最多可以储存 256 个不同字符。大部分语言中的所有字母、数字和控制符号（传输结束、字符串结束、为菜单绘制矩形的线条和边缘等）都符合该限制。

然而，对大多数国家而言，所选的 256 个字符的代码页并不包含数学中常用的希腊字母等字符。为了克服这类限制，人们发明了 Unicode：这种编码让英文文本照常工作，同时又能使用远多于 256 个的字符。

Unicode 替换

wxMaxima will replace several Unicode characters with their respective Maxima expressions, e.g. ² with ^2, ³ with ^3, ≠ with # or ≤ with <=.

Unicode characters that stand for a Maxima name are instead defined as Maxima aliases of that name when wxMaxima starts Maxima: π for pi, ⅈ for i, ⅇ for e, ∞ for inf, the (mathematical) Sigma sign (which is not the same Unicode character as the corresponding Greek letter) for sum, ∏ for product, ∫ for integrate, the square root sign for sqrt and ⋀, ⋁, ⊻, ⊼, ⊽, ⇒, ⇔ and ¬ for and, or, xor, nand, nor, implies, equiv and not. This means they work in files loaded by batch() or load(), too, and aliases lists the names they stand for. As Maxima reads these characters as letters they need to be separated from neighbouring names by spaces in such a file: a⋀b is a variable name, a ⋀ b means a and b. In an input cell wxMaxima adds these spaces automatically. It also puts parenthesis around a number or a variable that directly follows the square root sign, so √2 means sqrt(2).

Unicode 中有几个“常用”分数被编码为单个码位： ¼, ½, ¾, ⅐, ⅑, ⅒, ⅓, ⅔, ⅕, ⅖, ⅗, ⅘, ⅙, ⅚, ⅛, ⅜, ⅝, ⅞

在把输入发送给 Maxima 之前，wxMaxima 会把它们替换为 Maxima 中的表示形式，例如 (1/4)。此外还有 ⅟，会被替换为 1/；以及 ↉（用于棒球），会被替换为 (0/3)。

建议在输入单元格中使用 **Maxima 代码**（而不是这些 Unicode 码位）。理由：(a) 用于数学输入的字体可能不包含这些字符；(b) 如果把文档保存为 wxm 文件，通常可以被（命令行）Maxima 读取，而这些替换在命令行 Maxima 中当然不起作用。不过，从其他文档复制粘贴公式时，可能会出现这些字符。

侧边栏

通过侧边栏可以访问最重要的 Maxima 命令的快捷方式、目录、调试消息窗口或最近执行命令的历史记录等。可以通过“视图”菜单启用它们。它们都可以移动到 wxMaxima 窗口内外的其他位置。另一个有用的侧边栏可以用鼠标输入希腊字母。

在“目录”侧边栏中，只需用鼠标右键单击某个标题，再选择更高一级或更低一级的标题类型，即可提升或降低该标题的级别。

MathML 输出

一些文字处理软件和类似的程序能够识别 MathML 输入并自动把它插入为可编辑的二维公式，或者（如 LibreOffice）带有提供“从剪贴板导入 MathML”功能的公式编辑器。还有一些程序支持 RTF 数学公式。因此， WxMaxima 在右键菜单中提供了多个相应的菜单项。

Pasting LaTeX or MathML formulas

Edit → Paste LaTeX/MathML as Maxima Code (also in the right-click menu) converts a formula from the clipboard into a Maxima command, for example one copied from a paper, a web page or an equation editor. LaTeX may come with or without $…$, \(…\) or \[…\] around it, so \int_0^1 \frac{\sin x}{x}\,dx becomes integrate(sin(x)/x,x,0,1). The command goes where the cursor is, or into a new code cell. MathML pasted into a code cell with the ordinary Paste is converted the same way, since nobody wants the XML in a code cell. If MathML copied with Copy as MathML is pasted back, the result is the original command: wxMaxima adds it to the MathML as an annotation.

LaTeX and MathML describe what a formula looks like, not what it means, so the conversion has to interpret it. Fractions, roots, powers, subscripts (x_1 becomes the name x_1, a_{n+1} the array element a[n+1]), functions with or without parentheses (\sin 2x), \frac{d}{dx}, ‘f’(x), integrals ending indx, sums and products with limits,\lim_{x\to 0}, |x|and matrices are understood. Aneis Euler’s number, but aniis only the imaginary unit when set upright (\mathrm{i}), as it more often is an index. A product of a name and parentheses, likex(y+1), is taken as a product unless the name isf,g,hor longer than one letter. Anything without a single meaning, like\pm,\dots` or text, isn’t guessed at: wxMaxima says what it couldn’t convert instead. Check the command before evaluating it.

Links in text cells

A web address in a text cell that starts with http://, https:// or mailto: is shown as a link. Since clicking into a text cell places the cursor there, a link is followed by CTRL+clicking it (CMD+clicking on macOS), or by right-clicking it and choosing "Open Link"; hovering over it shows where it leads. The HTML export turns it into a link, the TeX export into a \url{}. Links are always recognized from the text itself, so nothing about them is stored in the file.

Links in a code cell's comments (/* ... */) work the same way. Elsewhere in code, for example inside a string, an address is Maxima syntax and is not a link.

The same goes for web addresses in Maxima's output, for example in a string printed by print("See https://wxmaxima-developers.github.io/wxmaxima/"): CTRL+clicking the address or choosing "Open Link" from its context menu opens it, while a plain click still selects the output.

Bold, italic, underlined and struck-through text

Text in a text cell, a title or a section heading can be made bold, italic, underlined or struck through. Select the text and press the respective button in the toolbar; pressing the button again removes that formatting from the selection. With nothing selected the button switches the formatting on or off for what is typed next. The buttons are hidden by right-clicking the toolbar and unchecking "Text formatting buttons". Code cells cannot be formatted: their colors already show the syntax of the code.

Superscript and subscript buttons work the same way: they make the text smaller and raise it above or lower it below the line, as in E = mc² or H₂O. A character cannot be both, so switching one of them on switches the other off. A line that contains a superscript, a subscript or a character that is taller than the font's usual ones, for example an emoji, gets as much additional room as it needs.

The formatting is saved in .wxmx files. Older versions of wxMaxima open such a file without the formatting but keep all of the text. .wxm files, the exports and the clipboard contain the text without its formatting.

  • CTRL+TAB 或 CTRL+SHIFT+TAB 触发自动补全。
  • SHIFT+SPACE 插入一个不可断行的空格。

Exploring output with the keyboard

A cell's output can be selected, and explored part by part, without a mouse:

  • DOWN at the end of a cell's input selects the first result of its output. Further presses of DOWN and UP step through the results; past the last one the cursor leaves the cell. If you prefer DOWN to skip over the output, switch on "Up/Down keys skip over output" in the Worksheet tab of the configuration dialog.
  • ENTER goes into the selected expression and selects its first part: the expression without its label, the numerator of a fraction, the name of a function, the first entry of a matrix, ... If the selection has no parts, ENTER opens a new input cell holding it, as it always did.
  • ESCAPE selects what the selection is a part of. From a whole result it goes back into the cell's input.
  • LEFT and RIGHT select the previous or next part at the same level. In a matrix all four arrow keys move from entry to entry.
  • SHIFT+LEFT and SHIFT+RIGHT grow or shrink the selection over the neighbouring parts; in a matrix, SHIFT and any arrow key grow the selected entry into a block of entries.
  • The context-menu key or SHIFT+F10 opens the right-click menu for the selection, so it can be copied in any format.

TeX 导出中的原始 TeX

如果文本单元格以 TeX: 开头，则导出 TeX 时，文件将包含 TeX: 标记后面的文本。使用此功能可以在 wxMaxima 工作簿中输入 TeX 代码。

文件格式

在 wxMaxima 中输入的内容可以存为以下三种文件格式之一，以供以后使用：

.mac

.mac 文件是包含 Maxima 命令的普通文本文件。可以用 Maxima 的 batch() 或 load() 命令，或者 wxMaxima 的“文件/批处理文件”菜单项读取它们。

下面是一个例子。 Quadratic.mac 定义了一个函数，随后用 wxdraw2d() 生成一张图。 之后打印文件 Quadratic.mac 的内容，并对新定义的函数 f() 求值。

注意：虽然文件 Quadratic.mac 使用的是 Maxima 的常规扩展名（<tt>.mac），但它只能被 wxMaxima 读取，因为命令 wxdraw2d() 是 wxMaxima 对 Maxima 的扩展。（命令行）Maxima 会忽略未知命令 wxdraw2d()，并把它原样作为输出打印出来。

可以用 .mac 文件编写自己的宏库。但由于它们不包含足够的结构信息，无法作为 wxMaxima 会话读回。

.wxm

.wxm 文件包含除 Maxima 输出之外的整个工作簿。在 Maxima 5.38 以上版本中，可以像 .mac 文件一样用 Maxima 的 load() 函数读取它们。嗯，大多数情况下可以。问题（例如 asksign(x)）会带来麻烦，因为答案会写入 .wxm 文件（以便加载后可以给出建议），但 Maxima 无法对其求值。 可以用 assume() 声明 Maxima 想要知道的属性，从而避免 Maxima 提问。

使用这种纯文本格式时，有时无法避免使用了新功能的工作簿与旧版本的 wxMaxima 不兼容。

wxm 文件的文件格式

这只是一个纯文本文件（可以用文本编辑器打开），以特殊的 Maxima 注释的形式包含各单元格的内容。

它以如下注释开头：

/* [wxMaxima batch file version 1] [ DO NOT EDIT BY HAND! ]*/
/* [ Created with wxMaxima version 24.02.2_DevelopmentSnapshot ] */

接下来是各个单元格，编码为 Maxima 注释，例如一个节单元格：

/* [wxMaxima: section start ]
Title of the section
[wxMaxima: section end ] */

或者（在数学单元格中，输入当然 没有 被注释掉；输出不会保存在 wxm 文件中）：

/* [wxMaxima: input start ] */
f(x):=x^2+1$
f(2);
/* [wxMaxima: input end ] */

图像采用 Base64 编码，第一行是图像类型：

/* [wxMaxima: image start ]
jpg
[very chaotic looking character sequence]
[wxMaxima: image end ] */

分页符只是一行，内容为：

/* [wxMaxima: page break ] */

折叠的单元格用以下标记：

/* [wxMaxima: fold start ] */
...
/* [wxMaxima: fold end ] */

.wxmx

这种基于 XML 的文件格式保存了完整的工作簿内容，包括缩放因子和观察列表等内容。它是首选的文件格式。

wxmx 文件的文件格式

wxmx 文件看起来像二进制格式，但可以用操作系统自带的工具处理。它是一个 zip 文件，可以用 unzip 解压（也许需要先重命名，以便操作系统的解压程序能识别它）。 我们没有使用压缩功能，只是利用了把多个文件合并成一个文件的能力：图像本身已经压缩过，其余部分是简单的文本（很可能比包含的大图像小得多）。

它包含以下文件：

  • mimetype：此文件包含 wxMaxima 文件的 MIME 类型： text/x-wxmathml
  • format.txt：关于 wxMaxima 和 wxmx 文件格式的简短说明
  • 图像（例如 png、jpeg）：在 wxMaxima 会话中生成的内嵌图形以及插入的图像。
  • content.xml：一个 XML 文档，以 XML 格式包含文档的各个单元格。

因此，如果出了问题，可以解压 wxMaxima 文档（也许需要先重命名为 zip 文件），用文本编辑器修改 content.xml 文件，或者替换损坏的图像，再把文件重新压缩，并把 zip 重命名为 wxmx 文件，这样就得到了一个修改过的 wxmx 文件。

WxMaxima 主要是 Maxima 的图形用户界面。因此，它的主要任务是把命令传递给 Maxima 并报告这些命令的执行结果。但在某些情况下， wxMaxima 也为 Maxima 增加了功能。前面已经提到， WxMaxima 能够把工作簿的内容导出为 HTML 和 LaTeX 文件来生成报告。本节介绍 wxMaxima 在会话中更好地插入图形的一些方式。

带下标的变量

wxsubscripts 指定 wxMaxima 是否（以及如何）自动把变量名的一部分显示为下标：

如果它的值为 false，则此功能关闭，wxMaxima 不会把变量名中下划线之后的部分自动显示为下标。

如果它的值为 'all，下划线之后的所有内容都会显示为下标。

如果它的值为 true，形如 x_y 的变量名在以下情况下以下标形式显示：

  • x 或 y 是单个字母，或者
  • y 是一个整数（可以包含多个字符）。

A variable the rules above don’t cover can still be declared as "to be subscripted" using the command wxdeclare_subscripted(variable_name); or wxdeclare_subscripted([variable_name1,variable_name2,...]); Declaring a variable as subscripted can be reverted using the following command: wxdeclare_subscripted(variable_name,false);, which also keeps a variable the rules above do cover from being subscripted.

wxdeclare_subscript(text_snippet); or wxdeclare_subscript([text_snippet1,text_snippet2,...]); instead declares a text snippet: every variable whose name ends in an underscore followed by that snippet is subscripted, however long the two parts are.

也可以使用菜单“视图->自动下标”设置这些值。

在状态栏中向用户反馈

运行时间较长的命令可以在状态栏中向用户反馈。放在那里的新反馈会替换旧的反馈（因此可以把它用作进度指示），并且当前发送给 Maxima 的命令一结束，反馈就会被删除。即使在可能与普通 _Maxima_（而不是 _wxMaxima_）一起使用的库中，也可以放心使用 wxstatusbar()：如果没有 _wxMaxima_， wxstatusbar() 命令只会保持未求值状态。

for i:1 thru 10 do (
/* 告诉用户我们进行到哪一步了 */
wxstatusbar(concat("Pass ",i)),
/* (sleep n) 是一个 Lisp 函数，前面加上 */
/* 字符 "?" 即可使用。它会推迟程序的 */
/* 执行（这里：推迟 3 秒） */
?sleep(3)
)$

在 Maxima 中导出工作簿

命令 wxworksheettohtml() 可以在运行中的 Maxima 会话里把当前工作簿导出为 HTML 文件，便于用脚本或批处理方式导出。和 wxstatusbar() 一样，它可以放心地用在可能也会在普通（控制台） Maxima 中运行的代码里：如果没有 _wxMaxima_，该命令只会保持未求值状态。

wxworksheettohtml("report.html")$
wxworksheettohtml("report.html", flavor="svg", wxmx=true)$

相对文件名以 Maxima 的工作目录为基准解释。可选的关键字选项有：

选项 取值 含义
flavor mathml（默认）、 mathjax、 svg、 bitmap 导出页面中公式的呈现方式
wxmx false（默认）、 true 嵌入一份可下载的会话 .wxmx 副本

The images and the .wxmx copy are written into a folder named after the HTML file, with _htmlimg appended. If "Embed images into the .html file" is checked in the Export tab of the configuration dialog, they are embedded into the HTML file instead, so it can be mailed as a single file.

flavor 的取值与图形界面 文件 → 导出 对话框提供的公式格式相对应： mathml 生成无需联网的独立页面， mathjax 为尚不支持 MathML 的浏览器添加 MathJaX 备用方案，而 svg/bitmap 把每个公式渲染为图像。

配套命令 wxworksheettotex() 以同样的方式导出为 LaTeX（<tt>.tex）文件：

wxworksheettotex("report.tex")$
wxworksheettotex("report.tex", documentclass="report", documentclassoptions="12pt,a4paper")$
选项 含义
documentclass 覆盖 LaTeX 的 \documentclass（例如 "article"、 "report"）
documentclassoptions 覆盖其选项（例如 "12pt,a4paper"）

计划支持 wxworksheettopdf()。

在工作簿中嵌入图形

Maxima 通常会让外部程序 Gnuplot 为它创建的每张图打开一个单独的窗口。由于很多时候把图形嵌入工作簿更方便， wxMaxima 提供了自己的一套绘图函数，它们与相应的 maxima 函数只有名称不同：都带有前缀“wx”。

以下绘图函数都有对应的 wx 版本：

wxMaxima 的绘图函数 Maxima 的绘图函数
wxplot2d() plot2d
wxplot3d() plot3d
wxdraw2d() draw2d
wxdraw3d() draw2d
wxdraw() draw
wximplicit_plot() implicit_plot
wxhistogram() histogram

如果使用这些函数时遇到问题，请检查对应的 Maxima 函数是否也存在同样的问题（例如 wxplot2d() 报错时，用 Maxima 命令 plot2d()（会在单独的窗口中打开图形）绘制同一张图试试）。如果问题依然存在，那很可能是 Maxima 的问题，应当在 Maxima 错误跟踪器 中报告。也可能是 Gnuplot 的问题。

放大或缩小内嵌图形

如上所述，配置对话框提供了一种修改所创建图形默认尺寸的方法，它设置的是 wxplot_size 的初始值。 wxMaxima 的绘图例程遵循这个以像素为单位指定图形尺寸的变量。随时可以查询它，或用它设置后续图形的尺寸：

wxplot_size:[1200,800]$
wxdraw2d(
explicit(
sin(x),
x,1,10
)
)$

如果只更改一个绘制图片的大小，wxMaxima 提供了一种只为当前单元格更改属性的方法。具体用法为，将 wxplot_size=[value1,value2] 附加到 wxdraw2d() 命令结尾，而不是作为该命令的一部分：

wxdraw2d(
explicit(
sin(x),
x,1,10
)
),wxplot_size=[1600,800]$

用 wxplot_size 设置内嵌图形的尺寸，适用于使用 wxplot、 wxdraw、 wxcontour_plot 和 wximplicit_plot 等命令生成的内嵌图形，以及使用 with_slider_draw 和 wxanimate 命令生成的内嵌动画。

wxplot_size tells Gnuplot how many pixels to draw. If a plot is wider than the window, wxMaxima shrinks it until it fits. If one specific plot is meant to be shown larger, even if that means it no longer fits on the screen, or smaller than that, the variable wxplot_scale (default: 1) tells wxMaxima to show it that many times as large as it would otherwise:

wxdraw2d(
explicit(
sin(x),
x,1,10
)
),wxplot_scale=2$

Unlike a bigger wxplot_size, which makes the text and lines of a plot smaller in relation to the plot, wxplot_scale makes everything larger, the text included. The factor is stored in the worksheet with the plot, so it survives saving and re-opening the file. It is respected by the same commands as wxplot_size. If wxMaxima shows plots as scalable vector graphics (see "Create scalable plots" in the configuration dialog) they stay sharp at any scale; a bitmap plot gets blurry if it is enlarged a lot.

A plot that should be wide but not high, for example a waveform, is better made with wxplot_size: a wider wxplot_size gives more room for the data, at the same height and with text of the same size. As such a plot would normally be shrunk to fit into the window, which makes its text tiny again, wxplot_scale='native tells wxMaxima to show it at exactly the size wxplot_size asks for, even if that is wider than the window:

wxdraw2d(
explicit(
sin(10*x)*exp(-x/3),
x,0,10
)
),wxplot_size=[1600,300],wxplot_scale='native$

更高质量的图形

Gnuplot 似乎没有提供一种可移植的方法来判断它是否支持 Cairo 库提供的高质量位图输出。在 Gnuplot 编译时使用了该库的系统上，配置菜单中的 pngCairo 选项（可以用变量 wxplot_pngcairo 覆盖）会启用抗锯齿和额外的线型。如果在 Gnuplot 不支持的情况下设置了 wxplot_pngCairo，得到的将是错误消息而不是图形。

在交互式 <em>Gnuplot</em> 窗口中打开内嵌图形

如果图形是用 wxdraw 类命令生成的（此功能不支持 wxplot2d 和 wxplot3d），并且底层 Gnuplot 项目的文件不是特别大， wxMaxima 会提供一个右键菜单，可以在交互式 Gnuplot 窗口中打开该图形。

在 <tt>plot</tt> 窗口中打开 Gnuplot 的命令控制台

在 MS Windows 上有两个 Gnuplot 程序： gnuplot.exe 和 wgnuplot.exe。 可以在配置菜单中设置使用哪一个。 wgnuplot.exe 可以打开一个控制台窗口，在其中输入 gnuplot 命令，而 gnuplot.exe 没有这个功能。遗憾的是，使用 wgnuplot.exe 时，每次准备绘图都会使 Gnuplot 短暂地“抢走”键盘焦点。

Animationen in das Arbeitsblatt einbetten

三维图形往往让人难以读出定量数据。一个可行的替代方案是把第三个参数交给鼠标滚轮。 with_slider_draw 命令是 wxdraw2d 的一个变体，它会预先生成多幅图形，并允许通过移动屏幕上方的滑块在它们之间切换。 WxMaxima 可以把这个动画导出为 GIF 动图。

with_slider_draw 命令的前两个参数是用于控制绘图的变量名称和变量值的列表，接下来的参数与 wxdraw2d 命令的参数相同：

with_slider_draw(
f,[1,2,3,4,5,6,7,10],
title=concat("f=",f,"Hz"),
explicit(
sin(2*%pi*f*x),
x,0,1
),grid=true
);

对三维绘图而言，类似的功能由命令 with_slider_draw3d 提供，可用参数来旋转三维图形：

wxanimate_autoplay:true;
wxanimate_framerate:20;
with_slider_draw3d(
α,makelist(i,i,1,360,3),
title=sconcat("α=",α),
surface_hide=true,
contour=both,
view=[60,α],
explicit(
sin(x)*sin(y),
x,-π,π,
y,-π,π
)
)$

如果重要的是图的大致形状，那么只要稍微移动一点，就可以直观地看出它的三维特征：

wxanimate_autoplay:true;
wxanimate_framerate:20;
with_slider_draw3d(
t,makelist(i,i,0,2*π,.05*π),
title=sconcat("α=",α),
surface_hide=true,
contour=both,
view=[60,30+5*sin(t)],
explicit(
sin(x)*y^2,
x,-2*π,2*π,
y,-2*π,2*π
)
)$

with_slider_draw and with_slider_draw3d make each frame out of a single 2D or 3D scene. with_slider_draw_bare instead hands the arguments that follow the variable and its values to a plain draw command. Each frame can therefore consist of several gr2d and gr3d scenes, and draw's global options like columns or dimensions can be used as well:

with_slider_draw_bare(
f,[1,2,3,4,5],
columns=2,
gr2d(
title=concat("f=",f),
explicit(sin(f*x),x,0,2*π)
),
gr3d(
explicit(sin(f*x)*cos(y),x,0,2*π,y,0,2*π)
)
);

Like with_slider_draw, with_slider_draw_bare accepts file_name="name", which saves the animation as name.gif in Maxima's working directory. As draw cannot turn a frame of several scenes into a single frame of a gif, wxMaxima assembles that gif from the frames it shows, and the animation is still shown in the worksheet. The gif file is only written when the command is evaluated in wxMaxima.

对于更熟悉 plot 而不是 draw 的用户，还有第二组函数：

  • with_slider 和
  • wxanimate。

通常，动画以 wxMaxima 设置中选定的帧率回放或导出。要设置单个动画的回放速度，可以使用变量 wxanimate_framerate：

wxanimate(a, 10,
sin(a*x), [x,-5,5]), wxanimate_framerate=6$

动画函数使用 Maxima 的 makelist 命令，因此也有同样的陷阱：只有当滑块变量直接出现在表达式中时，它的值才会被代入表达式。因此下面的例子会失败：

f:sin(a*x);
with_slider_draw(
a,makelist(i/2,i,1,10),
title=concat("a=",float(a)),
grid=true,
explicit(f,x,0,10)
)$

如果明确要求 Maxima 代入滑块的值，绘图就能正常进行：

f:sin(a*x);
with_slider_draw(
b,makelist(i/2,i,1,10),
title=concat("a=",float(b)),
grid=true,
explicit(
subst(a=b,f),
x,0,10
)
)$

同时在多个窗口中打开图形

这是 Maxima 的一个特性（在支持它的环境中），并不是由 wxMaxima 提供的，但有时会很方便。下面的例子来自 Mario Rodriguez 发到 Maxima 邮件列表的一篇帖子：

load(draw);
/* 在第 1 个窗口中绘制抛物线 */
draw2d(terminal=[wxt,1],explicit(x^2,x,-1,1));
/* 在第 2 个窗口中绘制抛物线 */
draw2d(terminal=[wxt,2],explicit(x^2,x,-1,1));
/* 在第 3 个窗口中绘制旋转抛物面 */
draw3d(terminal=[wxt,3],explicit(x^2+y^2,x,-1,1,y,-1,1));

也可以在同一个窗口中绘制多幅图形（在命令行 Maxima 中用标准的 draw() 命令同样可以做到）：

wxdraw(
gr2d(
key="sin (x)",grid=[2,2],

“使用 draw() 函数绘图”侧边栏

“使用 draw() 函数绘图”侧边栏中隐藏着一个简单的代码生成器，用它可以生成场景，从而利用 maxima 自带的 draw 程序包的一部分灵活性。

二维绘图

生成绘制二维场景的 draw() 命令的框架。之后需要用生成场景内容的命令来填充这个场景，例如使用“二维绘图”按钮下面几行中的按钮。

“二维绘图”按钮的一个实用功能是，它可以把场景设置为动画，其中某个变量（默认是 t ）在每一帧中取不同的值：与静止的三维图形中的相同数据相比，运动的二维图形往往更容易解读。

三维绘图

生成绘制三维场景的 draw() 命令的框架。如果既没有设置二维场景也没有设置三维场景，其他所有按钮都会设置一个二维场景，其中包含该按钮生成的命令。

表达式

在光标当前所在的 draw() 命令中添加绘图函数表达式，如 sin(x), x*sin(x) 或者 x^2+2*x-4 等 。每个图中可以绘制任意数量的图形。如果没有 draw() 命令，将调用绘制二维图形的模板。

隐式绘图

尝试寻找满足 y=sin(x)，y*sin(x)=3 或 x^2+y^2=4 之类的表达式的所有解，并在光标当前所在的 draw() 命令中绘制对应曲线。如果没有 draw() 命令，将调用绘制二维图形的模板。

参数式绘图

将变量（如 t）从下限变化到上限，并在当前绘图命令中使用两个表达式（如 t*sin(t) 和 t*cos(t)），以生成曲线上点的横、纵坐标 (x,y)（在三维图形中，第三个表达式生成竖坐标 z）。

点

绘制多个点，并且可以选择顺次连接它们。点的坐标取自列表的列表、二维数组或为每个轴指定的一个列表或数组。

图表标题

在图形上方绘制标题。

坐标轴

设置坐标轴。

等高线

（仅用于三维图形）为当前 draw() 命令中随后的绘图命令和/或图形的底面添加类似于山地地图上的等高线。此外，这个向导也可以完全不绘制曲面，只显示等高线图。

图形名称

在图形的图例中添加一项，显示下一个图形的名称。空名称会使后续的图形不再生成图例项。

线条颜色

为当前 draw() 命令所绘图形设置线条颜色。

填充颜色

为当前 draw() 命令所绘图形设置填充颜色。

网格

弹出设置网格线的向导。

精度

允许选择适当数目的点，以兼顾速度与精度（任何绘图程序都会权衡两者）。

修改图形的字体和字号

尤其是在使用高分辨率显示器时，默认字号可能非常小。对于基于 draw 的命令，可以用 font=...、 font_size=... 之类的选项设置字体和字号，例如：

wxdraw2d(
font="Helvetica",
font_size=30,
explicit(sin(x),x,1,10));

对于 plot 类命令（例如 wxplot2d、 wxplot3d），可以用 gnuplot_preamble 命令设置字体和字号，例如：

wxplot2d(sin(x),[x,1,10],
[gnuplot_preamble, "set tics font \"Arial, 30\"; set xlabel font \",20\"; set ylabel font \",20\";"]);

这会把数字的字体设为字号 30 的 Arial，并把 xlabel 和 ylabel 的字号设为 20（使用默认字体）。

更多信息请阅读 Maxima 和 Gnuplot 的文档。注意：Gnuplot 在较大的字号下似乎有问题，参见 wxMaxima issue 1966。

table_form(
[
[1,2],
[3,4]
]
)$

正如下一个例子所示，可以在执行 table_form 命令之前创建需要显示的列表。

此外，由于矩阵是含列表的列表，它也可以用类似的方式转换为表格。

函数 wx_matrix() 是 Maxima 的 matrix() 命令的包装，它允许在 wxMaxima 中更灵活地排版矩阵：

**wx_matrix( <matrix>, [options] )**

  • **lines=true**：在单元之间绘制内部分隔线。要在视觉上把标题和数据分开，就需要它。
  • **rownames=true**：告诉 wxMaxima 矩阵的第一列是标签。
  • **colnames=true**：告诉 wxMaxima 矩阵的第一行是标签。
  • **parenstyle=<style>**：设置矩阵周围的括号类型。支持的样式有： round ()、 square []、 angled <>、 straight || 或 none。
  • **oversized=<mode>**: Decides how this one matrix is shown if it is too large for the window, whatever the option Matrices too large for the window (see below) says: full draws it in full, elide leaves out its middle rows and columns, and scroll shows it in a box the size of the window, with scrollbars of its own.
  • **banding=<mode>**: Decides whether every other row and column of this matrix is faintly shaded (see below): true always shades them, even if the matrix fits the window, false never does, not even in the window double-clicking opens, and auto, the default, shades them only if the matrix is too large for the window.

示例：

wx_matrix(matrix(["Name", "Value"], ["X", 10], ["Y", 20]),
lines=true, rownames=true, colnames=true, parenstyle=square);

wx_matrix() doesn't display anything itself: it returns the matrix with the formatting attached, which is used whenever that value is displayed. So it can be stored in a variable and displayed later, formatted, and a matrix ended with $ isn't displayed at all. A new matrix calculated from it, for example by adding to it or transposing it, is displayed the normal way again.

A matrix cannot be broken into lines the way a long sum can. So by default wxMaxima leaves out the middle rows and columns of a matrix that is too large for the window and marks the gap with ⋯, ⋮ and ⋱, the way a large matrix is written by hand. The first and last rows and columns always stay visible, and hovering the mouse over the matrix tells which rows and columns are not shown. The option Matrices too large for the window in the Worksheet tab of the configuration dialog can instead draw such a matrix in full, which makes the whole worksheet scroll sideways, or show it in a box the size of the window, with scrollbars of its own; there the mouse wheel scrolls the worksheet, unless that matrix or something inside it is selected, and such a matrix is printed with its middle rows and columns left out. Whether it is elided or shown in a scrolling box, every other row and column of such a matrix is faintly shaded, so that a row or a column is easy to follow across it; a matrix that fits the window stays plain, unless wx_matrix()'s banding option says otherwise. All of this affects only what is shown on screen and printed: copying, saving and exporting the matrix always include every entry. wx_matrix()'s oversized option overrides that option for a single matrix; a matrix it asks to scroll is still elided on paper, and exporting a matrix as an image still always shows all of it. Double-clicking a matrix that is elided or shown in a scrolling box opens a window of its own that shows all of it; the window can be resized and scrolled, and Escape closes it. Ctrl+F in that window searches the matrix: each match selects the entry it is in and scrolls it into view, and searching again steps on to the next matching entry.

无法连接到 <em>Maxima</em>

Maxima （进行实际数学运算的程序）和 wxMaxima （提供易用的用户界面）是两个独立的程序，它们通过本地网络连接进行通信。因此，最可能的原因是这个连接由于某种原因无法工作。例如，防火墙的设置可能不仅阻止来自互联网的未授权连接（或许还会拦截一些通往互联网的连接），还阻止了同一台计算机内部的进程间通信。注意，由于 Maxima 是由 Lisp 处理器运行的，被阻止通信的进程不一定叫做 "maxima"。打开网络连接的程序的常见名称有 sbcl、gcl、ccl、lisp.exe 或类似名称。

在 Unix 计算机上，另一个可能的原因是为同一台计算机上两个程序之间提供网络连接的回环网络没有正确配置。

如何从损坏的 .wxmx 文件中挽救数据

在内部，大多数现代的基于 XML 的格式都是普通的 zip 文件。 WxMaxima 不开启压缩，因此 .wxmx 文件的内容可以用任何文本编辑器查看。

如果把损坏的 .wxmx 文件重命名为 .zip 之后，文件末尾的 zip 签名仍然完好，大多数操作系统都提供了提取其中所存储信息的任意部分的方法。当需要从文字处理文档中恢复原始图片文件时，也可以这样做。即使 zip 签名已经损坏，也不必绝望：如果 wxMaxima 在保存时发现出了问题，会留下一个 .wxmx~ 文件，其内容可能会有帮助。

即使没有这样的文件： .wxmx 文件是一种容器格式，其中的 XML 部分是未经压缩存储的。可以把 .wxmx 文件重命名为 .txt 文件，然后用文本编辑器恢复文件内容中的 XML 部分（它以 <?xml version="1.0" encoding="UTF-8"?> 开头，以 </wxMaximaDocument> 结尾。在这段文本前后，文本编辑器中会显示一些无法阅读的二进制内容）。

如果把只包含这些内容的文本文件（例如把这段文本复制粘贴到一个新文件中）保存为以 .xml 结尾的文件， wxMaxima 就能从该文档中恢复文本。

我希望在命令结束之前就在屏幕上显示一些调试信息

通常 wxMaxima 会等待最后的公式形成后才开始输出，这节省了多次尝试输出部分公式的时间。不过， disp() 命令可以立即输出调试信息，而不必等待当前的 Maxima 命令完成：

for i:1 thru 10 do (
disp(i),
/* (sleep n) 是一个 Lisp 函数，前面加上 */
/* 字符 "?" 即可使用。它会推迟程序的 */
/* 执行（这里：推迟 3 秒） */
?sleep(3)
)$

另外，也可以参考上文介绍的 wxstatusbar() 命令。

绘图只显示一个带有错误消息的封闭空信封

这意味着 wxMaxima 无法读取 Maxima 本应指示 Gnuplot 创建的文件。

这个错误的可能原因如下：

  • 绘图命令属于第三方程序包（例如 implicit_plot），但在尝试绘图之前没有用 Maxima 的 load() 命令加载该程序包。
  • Maxima 尝试做了当前安装的 Gnuplot 版本无法理解的事情。这种情况下， Maxima 的变量 maxima_userdir 所指向的目录中有一个以 .gnuplot 结尾的文件，其中包含 Maxima 发给 Gnuplot 的指令。因此在排查问题时，这个文件的内容大多数时候都会有帮助。
  • Gnuplot 被指示使用提供抗锯齿和额外线条样式的 pngCairo 库，但它在编译时没有启用这项支持。解决方法：在设置对话框中取消勾选“为嵌入式绘图使用 gnuplot 的 pngcairo 驱动程序”复选框，并且不要在 Maxima 中把 wxplot_pngcairo 设为 true。
  • Gnuplot 没有输出有效的 .png 文件。

绘制动画时出现“error: undefined variable”

默认情况下，只有当滑块变量出现在要绘制的表达式中时，它的值才会被代入。使用 subst 命令把滑块变量代入要绘制的方程即可解决这个问题。在 在工作簿中嵌入动画 一节的末尾可以看到一个例子。

单元格内容丢失了，撤销也找不回来

对单元格的操作和单元格内部的更改均有单独的撤消函数，因此发生这种情况的可能性很低。如果确实是这样，有如下方法可以恢复数据：

  • WxMaxima 实际上有两种撤销功能：没有选中单元格时起作用的全局撤销缓冲区，以及光标位于单元格内时起作用的单元格撤销缓冲区。值得把两种撤销都试一试，看看能否找回旧的内容。
  • 如果还能查到 Maxima 给该单元格分配的标签，只需输入该单元格的标签，它的内容就会重新出现。
  • 如果查不到：别慌。“视图”菜单中可以打开“历史记录”面板，其中显示最近执行过的所有 Maxima 命令。
  • 如果以上都没有帮助，可以调用 Maxima 的回放功能：
playback();

<em>WxMaxima</em> 启动时显示消息“Maxima process terminated.”

一个可能的原因是，在 wxMaxima 设置对话框的“Maxima”选项卡中设置的位置找不到 Maxima_，因此它根本无法运行。把路径设置为一个可用的 _Maxima 可执行文件应该就能解决这个问题。

Maxima 一直在计算，不响应输入

理论上， wxMaxima 可能没有察觉到 Maxima 已经计算完毕，因此永远得不到可以向 Maxima 发送新数据的通知。如果是这种情况，“触发求值”（Trigger evaluation）可能会让两个程序重新同步。

基于 SBCL 的 <em>Maxima</em> 内存不足

Lisp 编译器 SBCL 默认带有一个内存限制，使它即使在低端计算机上也能运行。在编译 Lapack 这样的大型软件包或处理极其庞大的方程列表时，这个限制可能太低了。要放宽限制，可以给 SBCL 传递命令行参数 --dynamic-space-size，告诉它应该预留多少兆字节。32 位 Windows 版 SBCL 最多可以预留 999 MB。在 Windows 上运行的 64 位 SBCL 可以被指示使用超过编译 Lapack 所需的约 1280 MB 内存。

给 Maxima （从而也给 SBCL）传递命令行参数的一种方法是 wxMaxima 设置对话框中的“Maxima 的附加参数”字段。

在 Ubuntu 上输入有时迟钝或会丢失按键

安装软件包 ibus-gtk 应该可以解决此问题. 详情见 https://bugs.launchpad.net/ubuntu/+source/wxwidgets3.0/+bug/1421558。

<em>Maxima</em> 处理希腊字母或变音字母时 <em>WxMaxima</em> 停止响应

如果所使用的 Maxima 基于SBCL，则必须将以下行添加到 .sbclrc 文件中：

(setf sb-impl::*default-external-format* :utf-8)

这个文件应该放在哪个文件夹取决于系统和安装方式。不过，任何一个基于 SBCL、在当前会话中已经计算过一个单元格的 _Maxima_，在收到下面的命令后都会乐于告诉你它的位置：

:lisp (sb-impl::userinit-pathname)

关于 Wayland 的说明（较新的 Linux/BSD 发行版）

On MacOS <tt>plot2d</tt> or <tt>draw</tt> open no window, but print “Broken pipe”

A message like

Broken pipe

means that Gnuplot stopped before Maxima could send it the plot. On MacOS the usual reason is that MacOS blocks a Gnuplot that was downloaded from the internet: since Maxima starts Gnuplot in the background, MacOS can't ask whether it may run. Starting Gnuplot once from a Terminal, or allowing it in System Settings => Privacy & Security, tells MacOS that it may; xattr -r -d com.apple.quarantine followed by the path of Gnuplot (for example Gnuplot.app) does the same. See wxMaxima issue #1461.

XQuartz isn't needed for plots in separate windows: neither wxMaxima nor Maxima chooses a Gnuplot terminal for them, so Gnuplot uses its own default one. That is qt for a Gnuplot from Homebrew and aqua (AquaTerm) for one from MacPorts, both of which draw without XQuartz. Only a Gnuplot that offers nothing but its x11 terminal, or GNUTERM set to x11, needs XQuartz. Embedded plots (wxplot2d, wxdraw and friends) never open a window and don't need any of this.

日志

日志消息有助于排查问题。WxMaxima 可以记录许多事件。大多数日志条目对开发者有用，尤其是在出现问题或缺陷时。如果运行的是“Release”版本， 日志窗口默认不显示；如果运行的是开发版本，它默认作为第二个窗口显示。可以通过菜单项“视图->Toggle log window” 打开或关闭这个窗口。

日志窗口不显示时，消息并不会“丢失”：如果之后选择显示日志窗口，就能看到以前的日志消息（只要没有清除它们）。

在提交错误报告（或自己查找缺陷）时，这些消息可能会有帮助。

使用命令行选项“–logtostderr”时，日志消息还可以（额外）输出到 STDERR。在 Windows 上会为此打开一个单独的文本控制台，因为 Windows 图形界面程序没有连接标准输入输出。

有暗色模式吗？

如果 wxWidgets 足够新，当操作系统的其余部分处于暗色模式时， wxMaxima 会自动进入暗色模式。工作簿本身默认使用明亮的背景，但可以另行设置。此外，还有一个 View/Invert worksheet brightness 菜单项，可以快速在暗色与明亮的工作簿之间切换。

Most images are drawn for a white background, and black line art with a transparent background would be invisible on a dark worksheet. So by default, if the worksheet background is dark, the transparent parts of images are filled with a backdrop color. Its color is the style Backdrop of transparent images in the Style tab of the configuration dialog, and the option Behind transparent parts of images in its Worksheet tab can switch the backdrop off, or draw it on a bright worksheet, too.

<em>WxMaxima</em> 有时在启动后的第一分钟内停顿几秒钟

WxMaxima 会把一些大任务（例如解析 Maxima 一千多页的手册）交给后台任务处理，这通常完全不会被察觉。但在需要这类任务结果的那一刻， wxMaxima 可能需要等待几秒钟才能继续工作。

尤其是在测试新的区域设置时，会出现消息框“locale ’xx_YY’ can not be set”

（其他应用程序也可能出现同样的问题。）点击“OK”之后翻译似乎正常。WxMaxima 不仅使用自己的翻译，也使用 wxWidgets 框架的翻译。

系统中可能没有这些区域设置。在 Ubuntu/Debian 系统上可以用以下命令生成它们： dpkg-reconfigure locales

如何使用表示实数、自然数等的符号（ℝ、ℕ）？

可以在 Unicode 侧边栏中找到这些符号（搜索“double-struck capital”）。但所选字体也必须支持这些符号。如果它们显示不正确，请选择其他字体。

Maxima 脚本如何判断自己是在 wxMaxima 中运行还是在命令行 Maxima 中运行？

如果使用的是 wxMaxima，Maxima 变量 maxima_frontend 被设置为 wxmaxima。此时 Maxima 变量 maxima_frontend_version 包含 wxMaxima 的版本。

如果没有使用前端（即使用的是命令行 Maxima），这两个变量的值为 false。

Is wxMaxima new enough for this worksheet?

wx_version_min("26.09.0") returns true if the running wxMaxima is at least version 26.09.0, and false if it is older, or if the command runs in command line Maxima. The parts of the version number are compared as numbers, so 26.10.0 counts as newer than 26.9.0, and a part that is left out counts as 0: wx_version_min("26.9") is the same as wx_version_min("26.09.0"). A development version counts as the version it will be released as.

wxMaxima 26.08.0 and older don't know wx_version_min() yet. There, as with any function Maxima doesn't know, the call isn't an error: it just returns itself, unevaluated, as wx_version_min("26.09.0"), which is neither true nor false. So a plain if wx_version_min("26.09.0") then ... stays unevaluated on these versions, too. A worksheet that has to work with them as well can compare the result with true, which gives false there:

if wx_version_min("26.09.0") = true then
wx_matrix(M, oversized=scroll)
else
M;

救命！我无法保存文档！

如果保存为 wxmx 文件不成功，可以尝试把文档保存为 wxm 文件（反之亦然）。也可以尝试移除所有输出（菜单 单元格->移除所有输出）后再保存，也许是某些意外的输出在保存过程中造成了问题。

命令行参数

通常，只需点击桌面图标或桌面菜单项就可以启动带有图形用户界面的程序。不过，WxMaxima 从命令行启动时仍提供一些命令行开关。

  • -v 或 --version：输出版本信息。
  • -h 或 --help: 输出简短的帮助文本。
  • -o 或 --open=<str>：打开作为此命令行开关参数给出的文件名
  • -e 或 --eval：打开文件后对公式单元格求值。
  • -b or --batch: If the command-line opens a file all cells in this file are evaluated and the file is saved afterward. This is for example useful if the session described in the file makes Maxima generate output files. Batch-processing will be stopped if wxMaxima detects that Maxima has output an error and will exit if Maxima asks a question no scripted answer exists for: Mathematics is somewhat interactive by nature so a completely interaction-free batch processing cannot always be guaranteed.
  • -d or --diff: Compare 2 or 3 files side-by-side using the Diff viewer.
  • --single_process: Open all worksheets from within the same process.
  • --single_thread: Run all background tasks from within the main thread.
  • --logtostderr: Log all "debug messages" sidebar messages to stderr, too.
  • --pipe: Pipe messages from Maxima to stderr.
  • --debug: Enable costly debug checks.
  • --exit-on-error: Close the program on any maxima error.
  • --language=<lang>: Use this language for the user interface instead of the one configured in the settings, for example de, pt_BR or zh_CN. The setting is not saved. Useful for checking a translation, or for making screenshots for a translated manual.
  • -f or --ini=<str>: Use the init file that was given as an argument to this command-line switch
  • -u, --use-version=<str>: Use maxima version <str>.
  • -l, --lisp=<str>: Use a Maxima compiled with Lisp compiler <str>.
  • -X, --extra-args=<str>: Allows to specify extra Maxima arguments
  • -m or --maxima=<str>: allows specifying the location of the maxima binary
  • --enableipc: Lets Maxima control wxMaxima via interprocess communications. Use this option with care.
  • --screenshot=<file>: Evaluate the file that is opened, save a screenshot as <file> once Maxima is idle and exit. What the screenshot shows is read from the [Screenshot] group of the configuration file given by --ini. Used for making the screenshots in this manual; see info/screenshots/README.md in wxMaxima's source code.
  • --wxmathml-lisp=<str>: Location of wxMathML.lisp (if not the built-in should be used, mainly for developers).

某些操作系统可能在命令行开关前使用破折号而不是减号。

On Linux and other Unix-like systems wxMaxima installs completions for bash, zsh and fish, so the Tab key completes these options and the names of the files wxMaxima can open.

A successful run exits with status 0. A batch run that had to stop before finishing exits with one of the following statuses instead, so a script that calls wxMaxima can tell why it stopped without reading its log:

  • 90: Maxima reported an error and --exit-on-error was given.
  • 91: Maxima asked a question no scripted answer exists for.
  • 92: The file named on the command line could not be opened.
  • 93: Saving the worksheet failed.
  • 94: The data of an image in the worksheet could not be loaded.
  • 95: An image in the worksheet could not be decoded (only checked with --debug).
