Detailed Description

A bitmap that is only drawn when a program asks for it.

wxBitmapDataObject is platform-specific (PNG on GTK, a HBITMAP or DIB on Windows), so rather than reimplementing any of that this hands the rendered bitmap to the base class the first time any of its data is asked for, and lets it do the rest.
