Detailed Description

Checks the things that commonly keep wxMaxima from working, and tells what it found.

The checks are grouped into pages, like the configuration dialog's settings, and each page's name starts with the symbol of its most important result. Each check is a row on its page: whether wxMaxima finds Maxima, whether Maxima starts, connects, prompts and authenticates, whether it loads packages and draw, whether gnuplot plots, whether the manuals, the help sidebar, a browser, the translations, SVG text and the AI sidebar are there. Selecting a row shows what was found and, for a problem, what can be done about it; "Copy report" puts all of it on the clipboard, for a bug report.

The checks that need Maxima or gnuplot are run by a TroubleshootingRunner, with a Maxima of its own, so the worksheet's Maxima is left alone; the dialog stays usable while they run. The others only ask wxWidgets and wxMaxima's own state, and are done at once.
