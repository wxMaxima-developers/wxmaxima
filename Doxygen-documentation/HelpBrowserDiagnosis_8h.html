wxString wxm::HelpBrowserDiagnosis ( )

A few lines saying what the integrated help browser needs and what was found.

The integrated help browser is a wxWebView. Whether wxMaxima can offer one depends on several things, any of which can be missing without an error message: wxMaxima has to be built with wxWebView, and on Windows wxWidgets must have been built with the Edge (WebView2) backend, the WebView2 loader must be found and the WebView2 runtime must be installed. This lists each of them, so that a user whose wxMaxima offers no integrated browser can tell – or send in a bug report – which one is missing.

The text is deliberately not translated: it is meant to be pasted into bug reports, and it names things (backends, DLLs, build options) that have no translation anyway.
