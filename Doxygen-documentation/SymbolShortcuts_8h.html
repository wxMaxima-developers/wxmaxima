Detailed Description

Keyboard shortcuts that type a symbol into the worksheet (GH #2578).

A "symbol" here is what one button of the Greek or the Symbols sidebar enters. It used to be exactly one character, which made a letter with a combining accent (t + U+0304 = t̄, GH #2296) two buttons, neither of which was what the user wanted. So a symbol is a short string: a base character together with the combining marks that follow it.

Everything in this file is free of GUI state, so the tests can pin it down without a window.

◆ SplitIntoSymbols()

std::vector< wxString > wxm::SplitIntoSymbols ( const wxString &  text)

Splits text into the symbols a sidebar shows as one button each.

A combining mark, a variation selector or the low half of a UTF-16 surrogate pair (wxString is UTF-16 on Windows) stays with the character before it, and a zero-width joiner joins its neighbours on both sides. So "Øt̄§" gives the three symbols "Ø", "t̄" and "§". A combining mark with nothing before it, or a space before it, is a symbol of its own. Spaces only separate symbols.
