Hands items to dispatch() until none is left or the time is used up.

Always handles at least one item, so a single item that takes longer than the whole budget can't stall the queue.

Parameters
budgetHow long to keep dispatching
takeFetches the next item; false if there is none
dispatchHandles one item; false stops the loop (for example because the connection the items came from is gone)
