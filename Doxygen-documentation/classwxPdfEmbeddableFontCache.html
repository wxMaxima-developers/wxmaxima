Detailed Description

Fonts resolved by wxPdfDocument::GetFontToEmbed() (embed-all-fonts mode)

Looking up an embeddable replacement may involve the operating system's font services, so the result is remembered per document. A cached invalid font means that no embeddable font was found; the warning about it has already been logged.
