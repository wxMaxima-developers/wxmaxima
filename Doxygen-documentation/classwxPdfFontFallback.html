Detailed Description

Internal state of the font fallback feature of one wxPdfDocument instance.

The state is kept out of the public header on purpose: it uses STL containers (which would trigger DLL-interface warnings in an exported class) and it is an implementation detail that may change without affecting the ABI of wxPdfDocument.

std::vector<wxPdfFontExtended> wxPdfFontFallback::m_resolved

Concrete fonts that were selected for at least one character ("slots")

Text runs refer to these by index. The fonts are kept as wxPdfFontExtended so that widths and glyph coverage can be queried without registering the font in the document; registration happens only when text is actually output.
