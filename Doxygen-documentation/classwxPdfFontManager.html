wxPdfFont wxPdfFontManager::FindFallbackFont ( wxUint32  unicodeChar,
int  fontStyle = wxPDF_FONTSTYLE_REGULAR 
)

Find an installed font containing a glyph for a character.

Searches the fonts installed on the system for a font that can show the given character, preferably in the given style. This is the lookup used by wxPdfDocument::SetSystemFontFallback(), but it can also be used directly, for example to build an explicit fallback list with wxPdfDocument::AddFallbackFont().

On wxGTK the fontconfig library is queried (the mechanism Pango uses for its own font fallback). On other platforms a built-in list of well-known font families with a large Unicode coverage is checked (e.g. Segoe UI and Cambria Math on Windows, Lucida Grande and STIX Two Math on macOS, DejaVu Sans and Noto Sans everywhere). A font found is registered with the font manager.

Results, including negative ones, are cached, so repeated lookups are cheap.

Parameters
unicodeCharthe Unicode code point of the character
fontStylethe preferred font style (only weight and italic are considered)
Returns
a font containing the character, or an invalid font if none was found
Note
Only available in Unicode builds. The result depends on the fonts installed on the system.

wxPdfFont wxPdfFontManager::GetEmbeddableFont ( const wxPdfFont &  font,
int  fontStyle = wxPDF_FONTSTYLE_REGULAR,
bool  useBuiltInReplacements = true 
)

Get an embeddable version of a font.

If the given font can be embedded, a copy of it with embedding enabled is returned. Otherwise an embeddable replacement font with matching style is searched in the following order:

  • the family defined by SetEmbeddableFontReplacement() for the font's family or alias;
  • for the Adobe standard fonts Helvetica, Times and Courier a built-in list of free fonts with compatible metrics (Liberation, Croscore, URW base 35, TeX Gyre, GNU FreeFont) followed by the common system fonts Arial, Times New Roman and Courier New.

Each candidate family is first searched among the registered fonts. If it is not registered yet, wxPdfDocument tries to locate the font via the operating system (on wxMSW, wxGTK and wxOSX, see RegisterFont(const wxFont&)) and registers it. A system font is only accepted if its family name equals the candidate family, so that a platform specific fallback font is never used silently.

Note
Locating a system font creates a wxFont object, so like RegisterFont(const wxFont&) this should be called from the main thread if the font is not registered yet.
Parameters
fontthe font to be made embeddable
fontStylethe requested font style (in addition to the style of the font itself)
useBuiltInReplacementsflag whether the built-in replacement lists are used; if false, only the replacement defined by SetEmbeddableFontReplacement() is tried
Returns
the embeddable font, or an invalid font if neither the font itself nor any replacement can be embedded
See also
SetEmbeddableFontReplacement(), wxPdfDocument::SetEmbedAllFonts()

◆ GetFontForWxFont()

wxPdfFont wxPdfFontManager::GetFontForWxFont ( const wxFont &  font)

Get the font corresponding to a wxFont object.

This method is used by wxPdfDocument::SetFont(const wxFont&), wxPdfDC and wxPdfGraphicsContext to map a wxFont to a PDF font.

First a registered font matching the face name and style of the wxFont is searched. If none is registered, the font is located via the operating system and registered (see RegisterFont(const wxFont&)).

If the face name denotes one of the 14 Adobe standard fonts or one of their aliases (for example Arial, Helvetica, Times, Courier or Symbol), the font installed on the system is preferred: a wxFont stands for the font the operating system renders on screen, while the standard fonts support only the WinAnsi character set (Symbol and ZapfDingbats only their own one) and are never embedded. Only if no font can be located via the operating system the standard font is used. The result is cached, so that the operating system is asked only once per face name and style.

Parameters
fontthe wxFont object
Returns
the matching font, or an invalid font if no font could be found
Note
It's the user's responsibility to check the font object before further using it.
This is not an overload of GetFont(): on wxMSW a wxFont can be constructed implicitly from a wxString, which made a call like GetFont(family) ambiguous.

bool wxPdfFontManager::SetDefaultEmbed ( bool  embed)

Set the default embedding mode.

Usually it is recommended to enable embedding, since this guarantees that no font substitution takes place on a target system not providing a required font.

The default embedding mode is enabled by default, but the embedding mode can be set for each font individually.

◆ SetEmbeddableFontReplacement()

void wxPdfFontManager::SetEmbeddableFontReplacement ( const wxString &  fontFamily,
const wxString &  replacementFamily 
)

Set the embeddable replacement for a font family.

Some fonts can never be embedded into a PDF document: the 14 Adobe standard fonts (Courier, Helvetica, Times, Symbol and ZapfDingbats), the Adobe CJK fonts, and fonts whose licence does not allow embedding. If a document requests that all fonts are embedded (see wxPdfDocument::SetEmbedAllFonts()), such a font is replaced by an embeddable font family. This method defines which family is used as replacement for a given font family.

Every PDF reader provides the standard fonts, so in embed-all-fonts mode they are only replaced if a replacement was defined with this method, or if the document conforms to PDF/A (which forbids non-embedded fonts).

The replacement family is tried first. If it is not available, the built-in list of metric-compatible free fonts is tried (see GetEmbeddableFont()).

The replacement family should either be registered already (for example with RegisterFont() or RegisterFontDirectory()) or be installed on the system, so that it can be located via the operating system's font services.

Note
The fonts Symbol and ZapfDingbats use a font specific encoding. Text written with them is reinterpreted using the encoding of the replacement font, so they should only be replaced by fonts with the same built-in encoding. Therefore no built-in replacements exist for these two fonts.
Parameters
fontFamilythe font family (or family alias) to be replaced, i.e. Helvetica
replacementFamilythe family of the embeddable replacement font, i.e. Liberation Sans. An empty string removes a previously defined replacement.
See also
GetEmbeddableFontReplacement(), GetEmbeddableFont(), wxPdfDocument::SetEmbedAllFonts()
