Detailed Description

Screenshots for the manual, made by wxMaxima itself (–screenshot).

The manual's screenshots used to be made by hand, on whatever desktop the person making them had, and so they aged: in 2026 the main window still showed version 19.10. info/screenshots/ describes each one as a scene (a worksheet, a configuration and what to show), and wxMaxima, started with –screenshot, opens the scene, evaluates it, waits until Maxima is idle and every image has been decoded, shows what was asked for, saves a PNG of it and exits. Doing that from inside the program means nothing has to guess how long evaluating or rendering takes.

The picture is read back from the screen, so it is meant to run under Xvfb (or any X11 display): a Wayland compositor does not let a program read the screen.

◆ ReadScreenshotScene()

std::optional< wxm::ScreenshotScene > wxm::ReadScreenshotScene ( const wxConfigBase &  config)

Reads a scene's [Screenshot] group.

  • show: window (the default), worksheet, cells, pane:<name> or config:<page>
  • sidebars: the sidebars to show, by AUI pane name, separated by commas; every other one is hidden. Left out: the layout stays as it is.
  • sidebarWidth: the minimum width of every sidebar shown.
  • width, height: the size of the main window, or of the dialog shown.
Returns
the scene, or no value if show names nothing we can show
