Detailed Description

The one definition of wxMaxima's command-line options.

Everything that describes the command line is made from this table:

  • the wxCmdLineParser description main.cpp parses with (and whose usage text is what –help prints),
  • the bash, zsh and fish completion scripts and
  • the OPTIONS section of the English man page. The last three are written by wxmaxima-genopts (src/genopts.cpp) at build time. That is why this header uses nothing but plain C++: the generator must build and run without wxWidgets and without a display.

The documents that cannot be generated – the German man page and the manual's "Command-line arguments" chapter, which po4a translates – are checked against this table by the ctest command_line_options_documented, so an option missing from them fails CI instead of going unnoticed.

The extensions (without the dot, lower case) of the files wxMaxima opens.

This is what the shells offer for the positional arguments and for –open. It mirrors ClassifyFileForOpening() (FileOpenKind.cpp); test_FileOpenKind checks that each of them is accepted there. Backup files (".wxm~") are deliberately left out: nobody wants them offered by Tab.
