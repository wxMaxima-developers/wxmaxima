Detailed Description

Pins the LaTeX export to the markup an expression actually needs.

The cells' ToTeX() used to wrap everything in braces "just in case" ({{x}^{2}}, {x_1}, \sin{(x)}), to use \left( \right) around anything that contained a "+", to make every operator a \mathop{} (which gives "=" the spacing of a \sum), to put \ensuremath{} into what always is math mode and to leave empty equations between two labels that a string replacement then half cleaned up. Each scenario here is one of these.

The maths is hand-written XML of the shape wxMathML.lisp emits, parsed by the real MathParser, so no Maxima is needed.
