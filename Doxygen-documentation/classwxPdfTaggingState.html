Detailed Description

State of the tagging machinery of one document (internal)

Marked content is managed as a small state machine. Page content is always written inside exactly one marked-content sequence created by this class: either the content of the innermost open structure element (/P <</MCID n>> BDC ... EMC) or an artifact (/Artifact BMC ... EMC) for content that the application did not tag, explicit artifacts and page headers/footers.

Sequences are opened lazily, i.e. only when page content is actually written (see wxPdfDocument::Out()), so that no empty sequences are created. They are closed at every structural boundary: BeginTag(), EndTag(), BeginArtifact(), EndArtifact(), EnterLayer(), LeaveLayer() and at the end of each page. Closing at every boundary guarantees that our sequences nest properly with other marked-content operators (optional content layers) and that a structure element spanning several pages gets one sequence per page.
