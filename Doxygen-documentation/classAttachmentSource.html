Detailed Description

The files a worksheet's XML refers to by name.

The XML of a cell doesn't contain its images: an <img> only names a file, which a .wxmx keeps next to content.xml in the same zip archive. The XML wxMaxima puts on the clipboard (GH #2474) has no zip archive around it, so it carries the same files base64-encoded in an <attachments> element instead (see Format::CellsToXMLDocument()). This class hides which of the two the files come from from everything that reads them.

An AttachmentSource is cheap to copy, and copies may be read from any thread: images and gnuplot sources are read by background tasks, which keep their own copy alive for as long as they need it.
