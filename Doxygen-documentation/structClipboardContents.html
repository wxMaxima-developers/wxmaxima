Detailed Description

Everything one copy operation puts on the clipboard.

The text and .wxm flavours are cheap, needed by nearly every paste and needed again by Worksheet::RenderClipboardContents(), so they are computed right away. Every other format is a LazyValue; one that is not offered stays empty.

The data objects share ownership of this, so it lives exactly as long as some data object built from it is still on the clipboard: a std::weak_ptr to it tells whether that is the case.
