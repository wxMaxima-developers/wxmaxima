Detailed Description

Selecting and copying a sub-matrix (GH #2345).

Dragging a rectangle across several entries of a matrix used to select the whole matrix. It now selects the block of entries the rectangle touches, and every "Copy ..." command copies just that block. These tests drive Worksheet::SelectOutputRect() – what a mouse drag in an output calls – with points taken from the laid-out entries, and check what gets selected and copied. The matrices are parsed from the XML Maxima sends, so no Maxima is needed, and nothing touches the system clipboard.
