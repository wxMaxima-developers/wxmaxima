Detailed Description

Where a run of several siblings sits: the level holding both of its ends.

For a selection that Shift+Left/Right grew over several siblings, which is not a node of the tree itself. firstIndex and lastIndex are the positions of the siblings the run starts and ends with. Found is false if no level has a sibling starting where the run starts and a later one ending where it ends.
