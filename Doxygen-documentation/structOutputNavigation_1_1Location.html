Detailed Description

Where an item sits in the tree.

path runs from the top-level result down to the item itself, and siblings is the level the item is one of (the results, for a top-level item), with index its position there. Found is false if the item isn't a node of the tree, e.g. a part of an expression selected with the mouse that doesn't match any node.
