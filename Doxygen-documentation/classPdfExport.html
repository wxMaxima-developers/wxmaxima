Detailed Description

Writes a worksheet to a PDF file.

The worksheet is drawn by the cells' own Draw() methods onto a wxPdfDC, so the PDF looks like the printout – but unlike a printout through a "print to PDF" driver:

  • the text stays text, in the worksheet's own fonts, embedded in the file;
  • characters the worksheet's fonts lack (Greek letters or maths symbols in a Latin-only font) are taken from another installed font that has them, as wxWidgets does on screen (wxPdfDocument's font fallback);
  • the PDF is tagged: a structure tree tells screen readers and text extraction what is a heading, a paragraph, code, a formula or a figure, in reading order. A formula carries Maxima's linear form of it as its alternate text and its MathML as an associated file, and a figure (a plot) the command that drew it.

The drawing needs wxPdfDocument (thirdparty/wxpdfdoc, see cmake/WxmPdfDoc.cmake): without it, Available() is false and Write() fails.

The export uses a copy of the worksheet laid out with a configuration of its own, the way Printout does, so the worksheet itself is left alone.

constexpr int PdfExport::LayoutPpi = 720
staticconstexpr

The resolution of the coordinates the worksheet is laid out in.

wxMaxima's geometry is integer, so this is also the precision of every position in the PDF: 1/720 inch, 1/10 of a point. Pdfout uses it, too.
