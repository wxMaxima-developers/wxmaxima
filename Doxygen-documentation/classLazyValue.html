Detailed Description

template<class T>
class LazyValue< T >

A value that is computed the first time it is asked for.

An empty renderer means "not offered"; see IsOffered(). The renderer is dropped once it has run, so whatever it captured (typically the shared ClipboardSnapshot) is freed as soon as nothing needs it any more.
