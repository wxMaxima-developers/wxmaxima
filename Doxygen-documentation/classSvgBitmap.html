Detailed Description

A wxBitmap with a constructor that generates the image from SVG.

The rendering is done by wxWidgets (wxBitmapBundle::FromSVG()); this class only unpacks our embedded data and keeps the bundle around, so a new size is rendered from the vector data again rather than scaled from pixels.
