Detailed Description

The standard wizards of wxMaxima's menus, described as data.

Most menu entries open the generic wizard (GenWizPanel): a few labelled fields and a command rule like "taylor(#1#,#2#,#3#,#4#);", in which #n# is replaced by the n-th field. Each of them used to need its own branch in a menu handler that passed up to 33 positional arguments, plus a Bind() in wxMaxima.cpp – and a forgotten Bind() left a menu entry that silently did nothing ("Dito, and evaluate the result" in the Calculus menu did, until this catalog bound it).

A wizard of that kind is now one WizardSpec in WizardCatalog(), and wxMaxima binds every ID the catalog names to one handler. Wizards that need more than text fields (checkboxes, choices, grids, file pickers) still have classes of their own.

This file needs no GUI, so test_WizardCatalog can check every entry.
