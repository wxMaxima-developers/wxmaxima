Detailed Description

Reads the size an SVG image says it has.

wxBitmapBundle::FromSVG() renders an SVG at whatever size it is asked for, but wxWidgets has no public way to ask the SVG how big it wants to be (its implementations know, but keep it to themselves, in 3.2 and 3.3 alike). An image in the worksheet needs exactly that, as its 100% size, so we read it from the root element ourselves: its width and height attributes, or its viewBox if those are missing or relative.
