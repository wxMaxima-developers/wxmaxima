Detailed Description

Keeps the per-cell memory footprint from creeping back up (GH #804).

A large result (a polynomial with a million terms) becomes several million cells, so every byte in Cell counts several megabytes. A cell's UUID and its unknown XML attributes used to be a wxString and a std::map in every cell (96 bytes on 64-bit Linux), although only GroupCells normally get a UUID; they now live in side data that is only allocated when used. This test checks both halves: that an ordinary maths cell allocates none of it, and that the data still survives the trip through MathParser and ToXML() for the cells that do carry it.
