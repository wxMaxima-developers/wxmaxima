Detailed Description

The sample worksheet of the configuration dialog's "Worksheet" tab.

A few cells, each with the output Maxima would send for it, so no Maxima is needed: labels (one user-defined, one automatic) and multiplication signs, special symbols and a Greek letter, a small fraction and one too wide for the window, a long number and a matrix too large for the window. Each Topic starts with a text cell naming it; when a setting changes, the dialog scrolls that heading to the top, so the cells the setting affects are in view.
