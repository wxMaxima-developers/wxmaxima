Detailed Description

Asks the user to press the keys that should type a symbol.

The keys are caught before any control of the dialog sees them, so a combination like Ctrl+Alt+T is recorded instead of acting on the dialog. Enter, Escape and Tab without Ctrl or Alt keep working as usual: they aren't usable as a symbol's shortcut anyway (see wxm::IsUsableShortcut()).

The dialog only records. What the shortcut is currently used for is asked of the function passed to the constructor, which is how the dialog can warn about a clash with a menu or another symbol without knowing where the shortcuts are kept.
