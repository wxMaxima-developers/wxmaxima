108 // current text via ClampToText(), so m_selectionStart / m_selectionEnd are
109 // always in [0, m_text.Length()] (e.g. CursorMove(-n) past the start clamps to
110 // 0 instead of wrapping a size_t to a huge value). The getters below keep a
111 // defensive std::min as well, because the text can still shrink *after* a
112 // selection was set without the selection being updated.
