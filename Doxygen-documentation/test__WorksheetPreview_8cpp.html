Detailed Description

The sample worksheet the configuration dialog's "Worksheet" tab shows to preview what its display settings do.

Checks that each topic the dialog scrolls to exists and is followed by the cells it is about, and that those cells react to the settings they are there to show. The output is parsed from the XML Maxima would send, so no Maxima is needed.
