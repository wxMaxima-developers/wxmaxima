◆ FileLooksBinary()

bool wxm::FileLooksBinary ( const wxString &  file)

True if the start of the file looks like binary data rather than text.

Looks at the first few kilobytes: a NUL byte, or the signature of a Windows, Linux or macOS executable, counts as binary. A file that can't be read counts as not binary; opening it will report that properly.

◆ MaximaStringLiteral()

wxString wxm::MaximaStringLiteral ( const wxString &  str)

A file name as a Maxima string literal, quotes included.

For building commands like load("file"). A file name on Linux and macOS may contain a double quote, which used to end the string early: importing a CSV file named data.csv"),system("... ran a shell command. A backslash is a Maxima escape character too, so an unescaped Windows path lost all of its backslashes.
