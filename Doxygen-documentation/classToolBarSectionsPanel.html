Detailed Description

Lets the user reorder the main toolbar's sections and show or hide them.

A list of all sections with a check box each (shown or not), in the order the toolbar shows them. wxWidgets' toolbars can't be rearranged by dragging their buttons around, so the list is where that happens: an entry can be dragged to another position with the mouse, or moved using the "Up" and "Down" buttons – which also work from the keyboard.

Nothing is stored before Write() is called, so "Cancel" in the dialogue leaves the toolbar as it was.
