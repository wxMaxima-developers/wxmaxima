Detailed Description

Items Maxima sent, on their way from the socket thread to the GUI thread.

Push() is called from the socket thread, everything else from the GUI thread; BackPressure() is safe from either.

◆ DefaultBackPressureChars

constexpr std::size_t MaximaItemQueue::DefaultBackPressureChars = 64 * 1024
staticconstexpr

The default for how much output may wait.

Enough for a GUI turn's worth of output even of the fastest flood seen (disp() in a loop, about 40 characters a line), and little enough that what is left to display after the user pressed Ctrl+G takes seconds, not minutes. A single item larger than this (a huge matrix) still gets through: the limit only stops the socket thread from reading more.
