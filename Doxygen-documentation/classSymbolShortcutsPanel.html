Detailed Description

The extra symbols of the Symbols sidebar, and the keyboard shortcuts of every symbol (GH #2578).

A table with one row per symbol: the symbol, its keyboard shortcut and which sidebar shows it. A symbol neither sidebar has built in becomes an extra symbol of the Symbols sidebar; one that is built in (α, ∞, ...) only gets its shortcut here. This replaces the text field the extra symbols used to be typed into, which they still are stored as, so older versions of wxMaxima keep reading them.

Nothing is stored before Write() is called, so "Cancel" in the dialogue changes nothing.
