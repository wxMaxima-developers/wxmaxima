Detailed Description

Renders a part of the worksheet as a PDF whose page is exactly as big as it.

This is a clipboard format: macOS programs (Keynote, Pages, Preview, ...) take vector graphics from the clipboard as PDF rather than as SVG, and a PDF keeps the text as text in the worksheet's own fonts, which are embedded. Characters these fonts lack come from another installed font, as on screen.

Unlike PdfExport there are no pages to break the cells into, no margins and no paper size: the page is cut to the cells. And unlike PdfExport it takes any list of cells, not only whole GroupCells.

It needs wxPdfDocument (see cmake/WxmPdfDoc.cmake); without it IsOk() is always false.

Is a PDF offered on the clipboard?

Not on Windows: no Windows program takes a PDF from the clipboard, and unlike on macOS and X11 there is no name for the format all programs agree on.
