Detailed Description

Tests the troubleshooting checks (GH #2559).

The helpers that interpret what a check found are tested directly. The runner, which starts a Maxima and talks to it, is tested against this very executable playing Maxima's part: started with –fake-maxima=<how> it misbehaves the way a broken Maxima installation can (exits at once, never connects, never prompts, sends a wrong secret), or answers the runner's questions the way a working Maxima would. No Maxima needs to be installed for that, so these tests run everywhere unit tests do.

The scenarios tagged [.maxima] run the checks against a real Maxima instead, named by the environment variable WXM_MAXIMA; test/CMakeLists.txt runs them as a test of their own wherever Maxima is installed. They are what notices if wxMathML.lisp or Maxima itself changes in a way the checks don't understand any more.
