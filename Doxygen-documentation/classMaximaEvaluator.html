Detailed Description

The evaluation-queue driver / command protocol extracted from wxMaxima.

Owned by value by the wxMaxima frame. Holds a reference back to that frame for the services it needs (the worksheet, the socket, the status bar).

◆ MarkErrorStatement()

void MaximaEvaluator::MarkErrorStatement ( GroupCell *  cell)

Marks the statement the current command came from as the one that caused an error, in the cell cell (GH #289).

Does nothing if the cell isn't the one that is being evaluated: an error can also arrive when nothing is, and there is no statement to blame then. Marks the statement only once per command, however many pieces the error message arrives in. If the error is a syntax error, also marks where in the statement it is, as soon as Maxima's output tells.
