Detailed Description

The command rules of the Matrix menu's wizards (GH #647).

Kept apart from the menu handlers so that a test can check which field ends up where: "Generate Matrix from Expression" used to ask for a width and a height, which users read the wrong way round, and its fields now say "Rows" and "Columns" – in the order "Enter Matrix" asks for them.

wxString wxm::GenMatrixFromExpressionRule ( )

The rule of the "Generate Matrix from Expression" wizard.

The fields are, in this order: #1# the expression each element is computed from, #2# the row index variable, #3# the column index variable, #4# the number of rows, #5# the number of columns. A matrix is a list of rows, so the outer makelist() runs over the rows.

The rule of a wizard that applies a one-argument function to a matrix.

The "Classic matrix operations" (invert(), determinant(), ...) used to insert their command with the selection, or %, as the argument, with no way to name the matrix before the command was sent. Their wizard's only field, #1#, is that matrix.
