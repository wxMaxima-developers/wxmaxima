Detailed Description

Selecting some of the characters of a text output with the mouse (GH #825).

The drags go through Worksheet::SelectOutputRect(), which is what a mouse move during a drag in an output calls, so what is tested is what the mouse does. Besides selecting characters, the tests pin how this gets along with the other kinds of selection: a drag that leaves the text selects whole cells, coming back selects characters again, and any other change of the selection forgets the characters. The output is parsed from the XML Maxima sends, so no Maxima is needed.
